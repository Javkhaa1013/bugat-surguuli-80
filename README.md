### А хувилбар — Бүх зургийг автоматаар татах (санал болгож байна)

**1. Хавтсаа нийтэд нээнэ**

Drive → зургийн хавтсан дээр баруун товч → **Хуваалцах (Share)** →
*Холбоос бүхий хүн бүр (Anyone with the link)* → **Үзэгч (Viewer)**.

**2. Хавтасны ID-г авна**

Хавтсаа нээхэд хаягийн мөрөнд:

```
https://drive.google.com/drive/folders/1AbCdEfGhIjKlMnOpQrStUvWxYz
                                        └────────── энэ хэсэг нь ID ──────────┘
```

**3. Google API түлхүүр авна** (үнэгүй)

1. https://console.cloud.google.com/ руу орж нэвтэрнэ
2. Дээд талаас шинэ **төсөл (project)** үүсгэнэ
3. **APIs & Services → Library** → `Google Drive API` хайж → **Enable**
   (бичлэг автоматаар татахыг хүсвэл `YouTube Data API v3`-г бас Enable хийнэ)
4. **APIs & Services → Credentials → Create credentials → API key**
5. Гарч ирсэн түлхүүрийг хуулж авна

**4. `data.js`-д бичнэ**

```js
drive: {
  folderId: "1AbCdEfGhIjKlMnOpQrStUvWxYz",
  apiKey:   "AIzaSy........................",
  folders: []
},
```

Болоо. Хавтас доторх бүх зураг автоматаар орж ирнэ.

**Олон хавтастай бол** (ангилал болгож харуулна):

```js
drive: {
  folderId: "",
  apiKey: "AIzaSy........................",
  folders: [
    { id: "хавтас_1_ID", label: "Ёслолын ажиллагаа" },
    { id: "хавтас_2_ID", label: "Урлагийн тоглолт" },
    { id: "хавтас_3_ID", label: "Төгсөгчдийн уулзалт" }
  ]
},
```

### А — Playlist-ээр (бүх бичлэг автоматаар)

YouTube дээр бичлэгүүдээ нэг **playlist**-д хийнэ. Холбоос нь:

```
https://www.youtube.com/playlist?list=PLxxxxxxxxxxxxxxxxxxxx
                                      └────── энэ нь ID ──────┘
```

```js
youtube: {
  playlistId: "PLSmJisvJrLd8",                // ← "Surguuli" жагсаалт, тохируулсан
  apiKey: "AIzaSy........................",   // ← энийг нэмбэл автомат шинэчлэлт асна
  channelUrl: "https://www.youtube.com/@DDAMJavkha"
},
```

`apiKey` нэмсний дараа: жагсаалтад шинэ бичлэг нэмэх бүрд сайт өөрөө шинэчилнэ.
Гарчгийг нь YouTube дээрээ засахад сайт дээрх нэр ч дагаж өөрчлөгдөнө —
давтагдах "СУРГУУЛИЙН ТҮҮХТ 80 ЖИЛИЙН ОЙН БАЯРЫН …" угтварыг сайт өөрөө хасаж,
гарчгаас нь ангиллыг таамаглана.

### Б — Гараар нэмэх (түлхүүр шаардахгүй)

```js
videos: [
  { id: "dQw4w9WgXcQ", title: "Ойн баярын нэгдсэн бичлэг", desc: "Бүрэн хувилбар", featured: true },
  { id: "aBcDeFgHiJk", title: "Урлагийн тоглолт", desc: "" },
],
```

`featured: true` тавьсан бичлэг том болж, хамгийн дээр гарна.
Бичлэгийн ID нь `youtube.com/watch?v=` **-ийн ард байгаа 11 тэмдэгт**.
